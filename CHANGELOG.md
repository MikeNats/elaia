# Changelog

## 0.1.0

First public release.

- Every project in one place: add a repo, and Elaia sets glafka up in it, step by step.
- A main chat per project: it plans one ticket, or writes an epic for bigger work.
- Epics with their own chat: it cuts the work into tickets, and their questions and approvals show up there.
- Every ticket gets its own git worktree, its own coder and its own chat.
- Buttons for each next step: answer, approve the plan, start the coder, push, merge, close.
- QA per acceptance criterion; tool calls and run reports sit behind Show details.
- Dots on the tree for anything new, and token counts for glafka's runs and the chat.
- The `elaia` command, so agents can search past specs, plans and chats.
